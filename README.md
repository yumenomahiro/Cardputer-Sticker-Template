# Cardputer and ADV Sticker Template~
So I noticed a disturbing lack of proper templates for this machine and made one in Affinity.

I took apart all the Stickers on my ADV and manually lined it up with a print of the Cardputer's and ADV's backplate stickers that, if I recall was posted by M5Stack themselves-
that's how I got the sizing to be as accurate as I could. Mine's the ADV but it should be the same aside from the back.

I will export a PSD version as well and update this from time to time.
